## Overview

This week, Copilot comes to JetBrains Air and Xcode's coding assistant, with updates to help you manage pull requests, settings, and agent sessions. 

GitHub Copilot app Set up Agent Merge allows you to set up the merge agent to run on your pull requests, enabling you to automate the merging process. This feature is particularly useful for large teams with complex pull request workflows. By integrating Agent Merge, you can streamline your development processes and reduce the time spent on merging code. With this update, you can focus on writing code rather than manually merging it.

## Key Features

The updates to the Copilot app include improved support for managing pull requests, including the ability to set custom labels and keywords. Additionally, the app now provides more detailed information about agent sessions, including the number of merged pulls and the time taken to merge them. This feature is especially useful for teams with high merge rates. By automating the merging process, you can save time and reduce the risk of human error. The updated app also includes improved support for managing settings, including the ability to set custom branch policies.
